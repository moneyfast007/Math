# פלוסי

אתר לתרגול מתמטיקה לילדים, מגן חובה ועד כיתה ו׳. עברית, RTL, מותאם לאייפד, עובד אופליין,
בלי איסוף מידע, בלי אנליטיקס ובלי שום תקשורת מחוץ לדומיין. סנכרון בין מכשירי המשפחה הוא אופציונלי
(ראו "סנכרון").

## כתובת

פרודקשן: https://math.assafkutai.workers.dev/ (כל push ל-`main`).

## פיתוח

```sh
npm ci
npm run dev          # http://localhost:5173
npm run check        # typecheck + lint + prettier + unit tests
npm run test:e2e     # Playwright: אייפד, אייפון, מחשב (דורש: npx playwright install webkit chromium)
npm run build        # dist/
```

עולמות "במאונך" (`src/engine/topics/vertical.ts`, `src/ui/Vertical.tsx`): השלב הראשון של כל פעולה מודרך (כל ספרה נבדקת
כשהיא נכתבת, טעות מוסברת, וטעות שנייה באותה ספרה נכתבת בשביל הילד); השלבים הבאים נכתבים שלמים ונבדקים בסוף.

כל עולם נכתב ב-`src/engine/topics/` בעזרת `src/engine/build.ts`: רמה סגורה (רשימת עובדות סופית,
כל משפט מוקלט שלם) או פתוחה (מחולל; המשפט מורכב מקליפים, `src/lang/compose.ts`).
בדיקות התכונות ב-`src/engine/topics/*.test.ts` עוברות על כל רמה בכל עולם: תשובה תקינה, בלי ספרות
בטקסט המוקרא, דוגמה פתורה ששונה מהתרגיל, ושכל מה שילד יכול לשמוע נמצא בבנק האודיו.

## אודיו

`npm run tts:build` (דרך ה-workflow "TTS build") מייצר את כל מה שחסר. מספרים ותוכן תרגילים:
WaveNet A; משפטי עידוד בודדים: Chirp 3 HD Leda. המשפט מורכב מקליפים כשאין הקלטה שלמה, תמיד בקול אחד.
הבנייה נעצרת אם משפט כלשהו מכיל ספרה.

## עקרונות שאסור לשבור

- ביטוי חשבוני מוצג תמיד דרך `<MathExpr>`; בדיקת ה-e2e נכשלת אם מספרים עם סימני פעולה
  מופיעים מחוץ לו.
- טקסט שמוצג למשתמש נמצא רק ב-`src/i18n/he.ts`.
- הטקסט המוקרא (`spokenText`) הוא שדה נפרד ולעולם לא מכיל ספרות.
- אין בקשת רשת לשום דומיין אחר. ה-CSP ב-`public/_headers` אוכף זאת. הסנכרון מדבר רק עם `/api`
  של אותו דומיין.

## סנכרון

אופציונלי, מאזור ההורים. המכשיר הראשון יוצר "משפחה"; מכשיר נוסף מתחבר בקוד של 6 ספרות שמוצג
במכשיר מחובר (תקף 10 דקות, לחיבור אחד). אין אימייל ואין סיסמה: לכל מכשיר אסימון משלו, ואפשר לנתק
מכשיר או למחוק את כל המשפחה מהשרת.

- **מה נשמר בשרת:** הפרופילים (שם, דמות, כיתה), ההתקדמות, וקוד ההורים כגיבוב עם salt. לא אימייל,
  לא כתובת IP (רק מונה ניסיונות קוד שגויים לשעה, נגד ניחוש), לא אנליטיקס.
- **איפה:** Durable Object לכל משפחה, באותו Worker שמגיש את האתר (`worker/`), באותו דומיין, כך שה-CSP
  לא השתנה.
- **בלי התנגשויות:** כל מכשיר כותב רק את ההתקדמות שנעשתה בו (slice), והאפליקציה מחברת
  (`src/sync/merge.ts`): מונים מתחברים, הרמה נלקחת מהמכשיר שקבע אותה אחרון. פרופילים וקוד הורים:
  השינוי האחרון גובר.
- **בלי אינטרנט:** האפליקציה עובדת כרגיל ומסתנכרנת כשהחיבור חוזר.
- **הגנה מתקלות:** לפני שנתונים מהשרת משנים את המכשיר נשמר בו עותק (שלושה ימים אחרונים), ואפשר
  לחזור אליו מאזור ההורים.

## פריסה

Cloudflare Workers Builds מחובר לריפו: כל push ל-`main` הוא פרודקשן. הבנייה: `npm run build`
(תיקיית פלט `dist`), והפריסה: `wrangler deploy` לפי `wrangler.json` (הקבצים הסטטיים, ה-Worker
וה-Durable Objects).
