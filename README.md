# פלוסי

אתר לתרגול מתמטיקה לילדים, מגן חובה ועד כיתה ו׳. עברית, RTL, מותאם לאייפד, עובד אופליין,
בלי איסוף מידע, בלי אנליטיקס ובלי שום תקשורת מחוץ לדומיין.

## כתובת

פרודקשן: https://math.assafkutai.workers.dev/ (כל push ל-`main`).

## פיתוח

```sh
npm ci
npm run dev          # http://localhost:5173
npm run check        # typecheck + lint + prettier + unit tests
npm run test:e2e     # Playwright: אייפד, אייפון, מחשב (דורש: npx playwright install webkit chromium)
npm run build        # dist/
```

```

  ui/         טוקני עיצוב, <MathExpr>, מקלדת מספרים, דיאלוג, לחיצה ארוכה, קבוצות גיל
  state/      מודל הנתונים, ולידציה, אחסון ב-IndexedDB, store, גיבוי ושחזור, קוד הורים
  profiles/   דמויות (אווטארים)
  parent/     שער הורים וטופס פרופיל
  screens/    מסכים: בית, ילד, הורים, התקנה, בדיקת תצוגה

  pwa/        עזרי התקנה

```

## עולמות (תוכנית הלימודים)

20 עולמות, 10 תחנות בכל אחד ותחנת סיום (חזרה מעורבת), לפי תוכנית משרד החינוך:

| כיתה    | עולמות                                                                                         |
| ------- | ---------------------------------------------------------------------------------------------- |
| גן חובה | מספרים עד 10 · חיבור וחיסור עד 20 (מתחנה 3) · צורות ודפוסים                                    |
| א׳      | חיבור וחיסור עד 20 · מספרים עד 100 · שעון וכסף                                                 |
| ב׳      | חיבור וחיסור עד 100 · כסף · כפל וחילוק: היכרות · שעון                                          |
| ג׳      | לוח הכפל · מספרים עד 10,000 · שברים: היכרות · שעון ומדידות                                     |
| ד׳      | מספרים גדולים · כפל וחילוק ארוכים · פעולות בשברים · שברים עשרוניים · היקף ושטח · זוויות וצורות |
| ה׳      | כפל וחילוק בשברים · פעולות בעשרוניים · אחוזים: היכרות · סדר פעולות · שטחים ונפחים              |
| ו׳      | אחוזים · יחס · מעגל ונפח                                                                       |

כל עולם נכתב ב-`src/engine/topics/` בעזרת `src/engine/build.ts`: רמה סגורה (רשימת עובדות סופית,
כל משפט מוקלט שלם) או פתוחה (מחולל; המשפט מורכב מקליפים, `src/lang/compose.ts`).
בדיקות התכונות ב-`src/engine/topics/*.test.ts` עוברות על כל רמה בכל עולם: תשובה תקינה, בלי ספרות
בטקסט המוקרא, דוגמה פתורה ששונה מהתרגיל, ושכל מה שילד יכול לשמוע נמצא בבנק האודיו.

## אודיו

`npm run tts:build` (דרך ה-workflow "TTS build") מייצר את כל מה שחסר. מספרים ותוכן תרגילים:
WaveNet A; משפטי עידוד בודדים: Chirp 3 HD Leda. המשפט מורכב מקליפים כשאין הקלטה שלמה, תמיד בקול אחד.
הבנייה נעצרת אם משפט כלשהו מכיל ספרה.

## עקרונות שאסור לשבור

- ביטוי חשבוני מוצג תמיד דרך `<MathExpr>`; בדיקת ה-e2e נכשלת אם מספרים עם סימני פעולה
  מופיעים מחוץ לו.
- טקסט שמוצג למשתמש נמצא רק ב-`src/i18n/he.ts`.
- הטקסט המוקרא (`spokenText`) הוא שדה נפרד ולעולם לא מכיל ספרות.
- אין בקשת רשת לשום דומיין אחר. ה-CSP ב-`public/_headers` אוכף זאת.
